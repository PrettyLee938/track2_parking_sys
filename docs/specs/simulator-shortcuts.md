# Simulator keyboard shortcuts

Source: `Track 2 specs.pdf`, page 37.

These are simulator-side practice controls. Do not use reset or penalty-clearing
shortcuts during a judged run unless the organizers explicitly permit them.

| Action | Shortcut |
| --- | --- |
| Pause | `P` |
| Exit | `Ctrl+E` |
| Full screen | `F11` or `Alt+Enter` |
| Remove cars | `Shift+C` |
| Clear penalties | `Shift+Z` |
| Repair all | `Shift+X` |
| Clear CO levels | `Shift+V` |
| Increase speed | `Shift+PageUp` |
| Decrease speed | `Shift+PageDown` |
